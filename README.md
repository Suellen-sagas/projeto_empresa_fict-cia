🏢 Empresa Fictícia
📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de simular o sistema de uma empresa fictícia, permitindo aplicar na prática conceitos de desenvolvimento de software, organização de projetos e controle de versões.

🎯 Objetivo

Criar uma aplicação para auxiliar no gerenciamento das atividades e informações da empresa, proporcionando uma solução simples, organizada e eficiente.

🚀 Funcionalidades
Cadastro de usuários
Cadastro e gerenciamento de produtos
Controle de informações da empresa
Consulta de dados
Atualização e exclusão de registros
Organização das informações

👩‍💻 Projeto acadêmico

Projeto desenvolvido para fins acadêmicos, com o objetivo de colocar em prática conhecimentos de desenvolvimento de sistemas, banco de dados e controle de versões.
